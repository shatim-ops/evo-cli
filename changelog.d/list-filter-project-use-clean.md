### Безопасность

- **Имена из облака в подсказке фильтра `lb_list`/`tg_list` и в выводе `evo project use` — без управляющих
  символов.** Было: отказ фильтра по неизвестному имени перечислял известные имена («Известные: …»), а отказ при
  нескольких одноимённых — их id, как облако их прислало; `evo project use` и его `--dry-run` печатали id и имя
  проекта из списка проектов как есть. Разделитель строк, символ направления или нулевой ширины менял вид строки.
  Стало: в подсказке фильтра каждое имя и id — в кавычках с экранированием, как остальные слова облака в этих
  отказах (`Известные: "lb-a", "lb-b".`); `evo project use` печатает их очищенными. `reason`, коды выхода и
  `--json` `evo project use` не меняются.
