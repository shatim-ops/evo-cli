### Миграция

- Раньше прямой вызов MCP `lb_create` с одним `confirmed: true` мог создать балансировщик в другой подсети после показа превью. Платное размещение балансировщика привязано к проекту, VPC, зоне и подсети. Для прямого вызова MCP запросите `lb_create` без подтверждения, покажите человеку превью и после его согласия передайте `preview_id` с `confirmed: true` в той же сессии. В HTTP сначала выполните `initialize` и передавайте `Mcp-Session-Id`. При изменении размещения покажите новое превью. Первый явный `evo lb create --yes` доступен человеку. Если стек остановился с `awaiting_lb_approval`, сохраните `job_id` и ID готовых ресурсов, запросите `stack_apply` для этого задания и подтвердите фактическое размещение. В MCP верните выданный `preview_id`. Опрос `stack_status` оставляет шаг на паузе. (D123)
