### Добавлено

- **`evo history --check` закрывает то, чего уже нет в облаке** (D43, минимум 1.9). Каждая живая строка «создано» или «найдено» читается по id тем же ключом, которым отправлен вызов, не больше 50 чтений за раз. Ресурс, которого больше нет (например, удалён в консоли), закрывается строкой `not_found` в журнале и попадает в `closed`. Остальные строки остаются живыми с `check_result`: найден, чтение не удалось, другой ключ, у вида нет чтения по id, нет id из облака, бюджет исчерпан. Облако только читается; без `--check` `history` по-прежнему не обращается к API. В MCP — аргумент `check` инструмента `history`.
