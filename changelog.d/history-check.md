### Добавлено

- **`evo history --check` называет то, чего ключ уже не видит в облаке** (D43, минимум 1.9). Каждая живая строка «создано» или «найдено» с id из облака читается по id тем же ключом, которым отправлен вызов. Старые строки идут первыми, не больше 50 чтений за раз. Ресурс, на который чтение отвечает «не найдено», попадает в `would_close`: он удалён (например, в консоли) или этот ключ его больше не видит. Остальные строки получают `check_result` — почему строка не прочитана: другой ключ, нет проекта, ресурс внутри родителя, создан меньше 10 минут назад, у вида нет чтения по id и т. д. `history` при этом ничего не пишет, журнал не меняется; облако только читается. Без `--check` — по-прежнему без обращения к API. В MCP — аргумент `check` инструмента `history`.
