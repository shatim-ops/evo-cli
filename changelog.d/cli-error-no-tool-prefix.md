### Изменено

- Ошибка команды CLI больше не начинается с имени инструмента MCP: `evo vm
  create` без зоны пишет «не задана зона доступности (region)», а не
  «provision: не задана зона…». `evo tools call <инструмент>` по-прежнему
  называет инструмент — его человек и набрал. Код выхода и `reason` не
  меняются.
