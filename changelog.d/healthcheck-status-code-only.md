### Безопасность

- **`evo mcp healthcheck` называет код ответа без текста сервера.** Было:
  при ответе не 200 ошибка печатала строку статуса целиком, с поясняющим
  текстом сервера. Сервер мог вписать туда query запроса (токен), логин или
  пароль адреса из `--url` или `MCP_HEALTHCHECK_URL`, и они выходили в
  stderr и в `error.message` при `--json`. Стало: «healthcheck: <адрес>
  answered HTTP 503» (по-русски — «проверка состояния: <адрес> ответил HTTP
  503»), где адрес — схема, хост и путь. Код выхода прежний.
