### Безопасность

- **Маскирование ответов MCP по HTTP (H7) закрывает значения переменных окружения, названных по-своему** (аудит Fable 1.5, FB15-44). Раньше значение пары `name`/`value` (env контейнера в `ca_get`, `ca_list`) маскировалось, только если имя содержит корень ключа (`password`, `secret`, `api_key`…): `GITHUB_TOKEN`, `BOT_TOKEN`, `DB_PASS`, `MYSQL_PWD`, `CREDENTIALS`, `AWS_ACCESS_KEY`, `SESSION_KEY` уходили открытыми, как и `DATABASE_URL=postgres://app:пароль@db`. Теперь маскируется значение, если имя оканчивается на `token`, `pass`, `pwd`, `credential(s)`, `key(s)` (кроме `PUBLIC_KEY`), и значение-ссылка с паролем внутри — при любом имени; `TOKEN_URL`, `ACCESS_KEY_ID`, `PASSWORD_POLICY` остаются видны. Ответ по-прежнему перечисляет замаскированное в `redacted`.
