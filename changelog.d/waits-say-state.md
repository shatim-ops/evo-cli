### Изменено

- **Ожидания называют состояние ресурса** (ось 2, #457). Раньше молчали до конца: `destroy` по `vm_id` ждал удаления ВМ до 2 мин, `deploy` ждал floating IP загрузки — готовности и привязки к ВМ, до минуты каждое, `deploy_apply` ждал SSH до 2 мин и повторял SSH для ключей человека до 4 раз. Теперь при каждой смене состояния — строка: «ВМ <id>: deleting, жду, пока она удалится…», «Floating IP <адрес>: creating…», «SSH на <адрес>: отказ в соединении, ВМ ещё загружается…», «SSH … повтор 2 из 3 через 10 с…». В CLI — в stderr, по MCP — в `notifications/progress`, если клиент их запросил; MCP `deploy` теперь шлёт ход и своих шагов, ответ и поле `log` не меняются.
