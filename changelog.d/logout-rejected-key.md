### Исправлено

- **`evo logout` с ключом, который IAM уже не принимает** (отозван в личном кабинете или истёк), удаляет профиль и отвечает `"key": "rejected"` с пояснением и обоими id ключа (`key_id`, `access_key_id`), вместо ошибки с кодом 5 и оставленного профиля, который пришлось удалять `evo configure delete`.
- **`evo logout` называет, до какого времени действуют токены**, которые ключ получил раньше (например, запущенный `evo mcp`): `tokens_valid_until` и строка в выводе — не позже этого времени они перестают действовать; evo их не отзывает.
- **Ответ `evo logout` — словами** («ключ удален», «ключа уже не было») вместо `ключ: deleted`; ошибка удаления ключа подписывает оба id — Key ID и id в IAM.
