### Исправлено

- **`evo logout` с ключом, который IAM уже не принимает** (отозван в личном кабинете или истёк), удаляет профиль и отвечает `"key": "rejected"` с пояснением, вместо ошибки с кодом 5 и оставленного профиля, который пришлось удалять `evo configure delete`.
- **`evo logout` называет, до какого времени действуют токены**, которые ключ получил раньше (например, запущенный `evo mcp`): `tokens_valid_until` и строка в выводе. IAM не отзывает их вместе с ключом.
- **Ответ `evo logout` — словами** («ключ удален», «ключа уже не было») вместо `ключ: deleted`; ошибка удаления ключа подписывает оба id — Key ID и id в IAM.
