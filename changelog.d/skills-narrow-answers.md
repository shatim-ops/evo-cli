### Изменено

- Правила для агента (`evo agent skill`, `docs/agent-skill.md`): `image_list`
  — только с `query`, образ для ВМ — по имени, без каталога; `metrics_scrape`
  — только с `match` (без него ответ — весь снимок, мегабайты).
- Скилл `evo-cleanup`: в инвентарь входят и ВМ развёртываний, найденные
  `status` и `list`, если `vm_name` начинается с `evo-<префикс>` — `deploy`
  называет их `evo-<project_name>`, и прежде уборка по префиксу их не
  видела. Развёртывания других проектов в рабочих каталогах в таблицу не
  попадают.
