### Изменено

- **Подключение агента по `docs/agent-setup.md`: агент сам ставит или обновляет evo.** Было: агент просил человека установить evo. Стало: строка «Настрой evo по…» — согласие на установку; агент запускает установщик (Linux и macOS — установка проверенных бинарников в `~/.local/bin`, автодополнение подключается отдельно; новая установка на обеих платформах требует cosign и проверяет личность выпуска, подпись checksums.txt и sha256 архива; Windows — PowerShell, каталог evo добавляется в `Path` пользователя), при второй копии evo в `PATH` не ставит повторно, а спрашивает. После подключения агент проверяет `whoami`, называет проект и предлагает первые действия. Запись в настройки клиента — по-прежнему после согласия.

  Переход: с уже установленным evo версии 1.9.0 или новее продолжайте настройку. Для установки или обновления агентом сначала установите доверенный cosign v3 либо установите evo вручную.
