### Изменено

- **Подключение агента по `docs/agent-setup.md`: агент сам ставит или обновляет evo.** Было: агент просил человека установить evo. Стало: строка «Настрой evo по…» — согласие на установку; агент запускает установщик (Linux и macOS — `install.sh` с `EVO_ZSHRC=0`, `~/.zshrc` не правится; Windows — PowerShell со сверкой sha256, каталог evo добавляется в `Path` пользователя), при второй копии evo в `PATH` не ставит повторно, а спрашивает. После подключения агент проверяет `whoami`, называет проект и предлагает первые действия. Запись в настройки клиента — по-прежнему после согласия.
