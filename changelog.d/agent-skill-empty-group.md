### Миграция

- **`evo agent skill --group ''` и MCP `agent_skill` с `group: ""` — `USAGE`, код 1** (класс DECISIONS D100; промежуточный дельта-аудит 1.9, FB19I-26 (б)). Было: команда печатала пустой вывод с кодом 0, а инструмент читал пустую группу как «без группы» и отдавал перечень групп. Стало: пустая группа и группа из пробелов — `USAGE` до вызова, в CLI и в MCP одинаково. Что поменять: не передавать `--group` (или `group`), когда группы нет; перечень групп отдаёт инструмент `agent_skill` без аргумента (`evo tools call agent_skill`).
