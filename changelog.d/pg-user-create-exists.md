### Изменено

- **`pg_user_create` (`evo pg user-create`): сбой создания пользователя,
  который есть в кластере, называет это прямо.** После сбоя evo читает
  пользователей кластера; пользователь с таким именем есть — подсказка
  говорит: удалять и создавать заново не нужно (сменится пароль, приложения
  перестанут подключаться) — спросите человека. Платформа отказала (4xx) —
  «уже существует, ничего не создано и не изменено»; ответа на создание нет
  (обрыв, тайм-аут, в том числе 408, 5xx) — «пользователь есть, его мог создать этот вызов».
  `reason` и код выхода прежние; пользователь, который был в кластере до
  вызова, — запрос создания не отправляется (`pg-create-repeat.md`). Пользователей прочитать не
  удалось или такого пользователя нет — ответ, как раньше.
