### Исправлено

- **Оценка ВМ по тарифной карте включает floating IP, если у ВМ будет публичный адрес** (план 1.7; агентный прогон M0 на 1.6.0: без ответа API оценка его не считала).
  - Превью `evo vm create`, `provision`, `evo deploy`, `deploy_plan` при молчании API расчёта цены: строка «цена» называет составляющие «вычисления + диск + floating IP», итог — их сумма; в `--json` — `floating_ip_monthly_rub`. Без публичного адреса (`--no-public-ip`) — как раньше.
  - Ставка floating IP в карте — 149,33 ₽ в месяц, как отвечает API (0,204 ₽ в час, месяц 732 часа); своя — `floating_ip_monthly` в `pricing.json`. Пример: ВМ lowcost10-2-4 с диском 20 ГБ — ~2421,73 ₽ в месяц вместо ~2272,40.
  - Цена из API (`price-calculation`) не меняется: floating IP в ней был и раньше.
