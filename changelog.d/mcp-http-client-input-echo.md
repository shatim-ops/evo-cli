### Безопасность

- **MCP HTTP не повторяет ввод клиента в журнале и в отказе.** Было:
  журнал сервера (stderr) писал имя инструмента из `tools/call` и
  HTTP-метод запроса как их прислал клиент — метод ещё до проверки
  токена; отказ на неподдерживаемый `Mcp-Protocol-Version` возвращал
  значение заголовка в теле. Стало: журнал называет инструмент реестра
  или `unknown`, метод HTTP или `other`; отказ называет поддерживаемые
  версии протокола. Статусы HTTP прежние.
