### Добавлено

- Каждый запрос evo к API Cloud.ru несёт заголовок `X-Request-Id` (новый UUID; повторы одного запроса — с тем же), а ошибка ответа API или обрыв без ответа называют его в конце сообщения: `… (X-Request-Id 3f2a…)`, и id ответа сервиса, если он свой: `(X-Request-Id 3f2a…, в ответе 9c1e…)`. Эти id называйте поддержке Cloud.ru — по ним она находит запрос. Одинаково в CLI и MCP; код выхода и `reason` не меняются (`docs/exit-codes.md`, «Формат ошибки»).
