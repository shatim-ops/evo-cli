### Добавлено

- **Карточки групп инструментов для агента** (#515, вариант А, слой B).
  - `evo agent skill --group <группа>` печатает карточку группы, с `--json` — `{"skill": …}`. В карточке: все инструменты группы с командами; что делает каждый — читает, меняет, создаёт или удаляет; откуда брать id (`cluster_id` ← `pg_list`); где id созданного, каким списком его найти и чем удалить; чем ждать асинхронную операцию (`*_operation`).
  - Карточки собираются из объявлений реестра, поэтому покрывают все 155 инструментов и не расходятся с кодом. Копии лежат в `docs/agent-cards/`.
  - `evo agent setup --skill` для клиентов, у которых правила — отдельный скилл (`claude-code`), пишет карточки групп агента (`--toolsets`) в `cards/` рядом с `SKILL.md`. Правила `evo agent skill` говорят, где их взять.
