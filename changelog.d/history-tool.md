### Добавлено

- **`evo history` и инструмент `history`: чтение журнала изменений** (D43, минимум 1.9). Ответ — строки журнала этой папки состояния за последние 30 дней (или с `--since`, не больше 500) и `live` — что может оставаться в облаке: создано и не удалено или с неизвестным итогом, с `check` — инструментом, который это прочитает. Записи намерения без строки (вызов убит до конца) тоже в `live`. Только чтение, локально, без обращения к API; инструмент есть при любом `--toolsets` и на `--read-only`. `journal_of` называет папку по базовому имени — локальный путь по MCP не уходит; `evo history` печатает и полный путь журнала. Строка не в форме evo пропускается и считается (`skipped`); значения из файла помечены `_untrusted`. На сервере с `--allow-project` — только строки его проектов; строки без проекта (вызов по id) не отдаются, их число — в `hidden_without_project`.
