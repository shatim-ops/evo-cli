### Исправлено

- Автодополнение Bash работает без пакета bash-completion. Установщик предлагает подключить файл из `~/.bashrc`; при установке через канал это можно разрешить переменной `EVO_BASHRC=1`. Команды для текущей оболочки приведены в `evo completion bash --help`.

- Установщик создаёт файл автодополнения fish, когда команда `fish` доступна в `PATH`. При удалении evo установщик убирает и файл, оставшийся от прежней установки fish.
