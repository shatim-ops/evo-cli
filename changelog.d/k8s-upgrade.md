### Добавлено

- `evo k8s upgrade` обновляет управляющую часть кластера до указанной версии. После проверки версии кластера `evo k8s nodepool-upgrade` обновляет одну выбранную группу узлов с отдельным подтверждением. Повторный вызов проверяет сохранённую операцию и фактическую версию ресурса. В MCP доступны `k8s_upgrade` и `k8s_nodepool_upgrade`. Для обеих команд доступен явный `--yes` человека в CLI. В MCP запросите превью и покажите его человеку. После его согласия передайте `preview_id` этого превью вместе с `confirmed: true` в той же сессии. При изменении проекта, ресурса, родителя, исходной или целевой версии требуется новое превью. При явном отказе API статус `rejected` завершает попытку. Для следующей попытки MCP требуется новое превью и согласие. При тайм-ауте или неизвестном исходе evo сохраняет квитанцию и предлагает прочитать карточку ресурса.
