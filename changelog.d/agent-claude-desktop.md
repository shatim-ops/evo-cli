### Добавлено

- **`evo agent setup --client claude-desktop`** (macOS, Windows): сервер evo в `claude_desktop_config.json` в каталоге настроек пользователя — тем же слиянием, с diff, вопросом, `--dry-run` и `--force`, что у остальных клиентов; повтор ничего не меняет. Приложение не читает `PATH` оболочки, поэтому запись называет путь, по которому запущен этот `evo`, — ссылку не раскрывая: обновление через Homebrew его не ломает, после переноса evo в другое место команду нужно повторить. `--http` для Claude Desktop отказывает (`USAGE`, код 1) до записи: файл приложения держит только серверы, которые оно запускает само. На Linux, где приложения нет, команда отказывает (`USAGE`, код 1), `--print json` печатает запись.
