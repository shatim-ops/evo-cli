### Добавлено

- **`evo agent setup --client claude-desktop`** (macOS, Windows): сервер evo в `claude_desktop_config.json` в каталоге настроек пользователя — тем же слиянием, с diff, вопросом, `--dry-run` и `--force`, что у остальных клиентов; повтор ничего не меняет. Приложение не читает `PATH` оболочки, поэтому запись называет полный путь к этому `evo`; после переноса или переустановки evo команду нужно повторить. `--http` для Claude Desktop отказывает (`USAGE`, код 1) до записи: файл приложения держит только серверы, которые оно запускает само. На Linux, где приложения нет, запись печатается.
