### Изменено

- **Отказ `evo vm create` и `provision` без зоны называет зону по умолчанию.** Было: «Задайте --region (список:
  evo vm zones) или evo configure --region <зона>», без зоны. Стало: если список зон отмечает зону по умолчанию и она
  принимает новые ресурсы, подсказка называет её и точный флаг: «Зона по умолчанию — ru.AZ-2 (evo vm zones): добавьте
  --region ru.AZ-2 или запомните её в профиле: evo configure --region ru.AZ-2»; по MCP — `region: "ru.AZ-2"`, в ответе
  поле `default_zone`. Нет отметки или список не прочитан — подсказка прежняя. Код выхода, `reason` (`CONFIG_INVALID`)
  и `missing` не меняются; превью не меняется.
