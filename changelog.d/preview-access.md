### Изменено

- **Превью называет, кому открывается создаваемое** (план 1.5, С4; аудит «слепые зоны» 1.5). `evo k8s create` и MCP `k8s_create` показывают в превью «API извне: да/нет» (`kube_api_internet`): раньше API кластера открывался из интернета по умолчанию, а превью об этом молчало (FB15-41). `evo kafka create` и MCP `kafka_create` показывают «Kafka UI: да/нет» (`ui_enabled`, FB15-35). Превью `ar_create`, `ca_deploy` и `lb_create`, которые уже называли `public` и `external`, подписывают их для человека: «доступ из интернета», «публичный адрес».
