### Миграция

- **`evo dns zone-create --type private` и MCP `dns_zone_create` с `type=private` привязывают зону к VPC, а без VPC отказывают до согласия** (решение владельца 30.10, #597 п. 15).
  Было: приватная зона создавалась без `linkedVpcIds` — нигде не разрешалась (нерабочий ресурс), код 0.
  Стало: зона привязывается к VPC из нового аргумента `vpc_id` (`--vpc-id`), иначе к VPC проекта по умолчанию; превью называет VPC (`vpc_id`, `vpc_name`). В проекте без VPC по умолчанию и без `vpc_id` — `USAGE`, код 1, до вопроса; `vpc_id` не из проекта — `NOT_FOUND`, код 4; `vpc_id` у публичной зоны — `USAGE`, код 1.
  Что поменять: скрипт, который создавал приватную зону в проекте без VPC по умолчанию, передаёт `--vpc-id`.
