### Добавлено

- **`install.sh` ставит автодополнение по Tab и умеет удалять evo** (решение владельца 28.10). Файл автодополнения кладётся туда, где оболочка находит его без правки конфигов: fish — `~/.config/fish/completions/evo.fish`, bash — `~/.local/share/bash-completion/completions/evo` (нужен пакет bash-completion), zsh — каталог из `$fpath` в домашнем каталоге. Иначе для zsh, а также для PowerShell, скрипт печатает строку для профиля. Конфиги оболочек не меняются. Повторная установка перезаписывает только свои файлы; `install.sh --uninstall` (`curl … | sh -s -- --uninstall`) убирает бинари evo и `cloudru-vm` и эти файлы.
