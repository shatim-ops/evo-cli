### Добавлено

- **Tab дополняет значения-ссылки на ресурсы облака во всей CLI** (решение владельца 28.10, догфуд). Зона, flavor, образ, подсеть, VPC, бакет, путь секрета, проект, id и имена ресурсов в `get`, `delete`, `attach` — во флагах и позиционных аргументах всех команд, в `evo deploy` и в `--region`, `--project-id`; набранное начало сужает список. Какой список дополняет какой аргумент, объявляет реестр инструментов — одна точка для всех команд. Только чтение: без согласия и записи в журнал, значения секретов не читаются; список кэшируется на 3 минуты (id и имена, файл `0600`), облако без ответа за 1,5 с — пустой список, без ключа — тишина. Настройка оболочки и меню стрелками — `docs/install.md`, «Автодополнение по Tab».
