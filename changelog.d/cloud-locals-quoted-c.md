### Безопасность

- **id и состояния из облака, переданные через переменную, — тоже в кавычках.** Ответы создания, которое облако
  делает после ответа (`subnet_create`, `snat_create`, `disk_create` и другие с ожиданием), отказы
  `deploy_apply` по уже применённому плану, отказ `release_floating_ip` по адресу SNAT-шлюза или ВМ и шаги
  `stack_apply`: id ресурса, имя и состояние ВМ из облака в тексте evo теперь в кавычках с экранированием.
  `reason` и коды не меняются.
