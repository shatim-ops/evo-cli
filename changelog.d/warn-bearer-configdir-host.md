### Исправлено

- **Предупреждение о коротком `MCP_BEARER_TOKEN` называет риск.** Если
  `evo mcp --http` на loopback запущен с токеном короче 32 символов,
  предупреждение говорит не только о длине: такой токен может подобрать
  процесс или страница, которым виден порт, и вызывать инструменты ключом
  сервера. `docs/mcp.md` требует токен не короче 32 символов.
- **`CLOUDRU_CONFIG_DIR`, заданная пустой, больше не молчит.** Пустое
  значение по-прежнему читается как отсутствие переменной, и evo берёт
  каталог настроек по умолчанию с профилями человека. Теперь об этом есть
  предупреждение в stderr и в `evo doctor` — с путём каталога.
- **`docs/mcp.md`: при `--auth bearer` заголовок `Host` не проверяется.**
  Этот режим — для клиентов не с loopback, подлинность запроса подтверждает
  токен.
