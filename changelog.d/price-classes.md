### Добавлено

- **Класс цены у каждого ресурса превью** (план 1.7, блок C; решение владельца 31.10): в ответе MCP и в `--json` превью создания — `preview.price_classes: [{resource, class, note}]`, по строке на каждый создаваемый ресурс (ВМ — сама ВМ, загрузочный диск и floating IP при публичном адресе). `priced` — цена в `preview.cost`; `zero_at_create` — при создании 0, оплата по использованию, `note` называет, что тарифицируется; `paid_unpriced` — ресурс платный, цена неизвестна, `note` — почему. «0» evo пишет только там, где это утверждает тариф Cloud.ru.

### Изменено

- Превью бакета (`evo s3 bucket-create`, `s3_bucket_create`): `цена: при создании 0 ₽; оплата по использованию — хранение, операции и исходящий трафик бакета: тариф …` (было «evo её не рассчитывает, ресурс платный») — так считает тариф Object Storage.
- Превью ресурса без цены говорит одинаково и называет причину: `цена: цена неизвестна, ресурс платный: <почему>; тариф …` — например, `цены Managed Kubernetes нет до калькулятора (D17)`, `в тарифах строки для него нет` (было «evo её не рассчитывает, ресурс платный: тариф …», «…; считайте его платным», у плагина кластера — «своей нет: плагин работает на узлах кластера…»). В `cost_note` — `price unknown, the resource is billable: …`.
