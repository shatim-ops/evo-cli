### Исправлено

- В машинных ответах CLI и MCP поле `_untrusted` указывает на `existing_id` при занятом имени ресурса и на `id` в результате удаления VPC по имени. Агент может распознать UUID, который evo получил из каталога проекта.
- Если имя VPC уже занято, подтверждённый вызов MCP возвращает отказ после чтения каталога. В журнале изменений не появляется строка о новой попытке создания.
