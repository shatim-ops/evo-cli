### Добавлено

- Переменная `EVO_RECORD_ANSWERS=<файл>` (для проверки самого evo, её ставит cloud-e2e): каждый ответ API Cloud.ru, пришедший по сети, дописывает в файл строку JSON с формой ответа — метод и адрес без query (UUID и числа пути — `{id}`), статус, пути полей тела с видом значения (`uuid`, `name`, `number`…). Значений в файле нет: ни строк, ни ключей объектов не формы имени поля (они — `*`), ни заголовков, ни тел запросов; тело не JSON — `"form":"not-json"`. Файл создаётся с правами 0600 и только дописывается; без переменной ничего не пишется, ответ и ход вызова запись не меняет. Из таких файлов собирается каталог живых ответов, по которому сверяются тестовые миры evo.
