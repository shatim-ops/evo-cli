### Добавлено

- Переменная `EVO_RECORD_ANSWERS=<файл>` (для проверки самого evo, её ставит cloud-e2e): каждый ответ API Cloud.ru, пришедший по сети, дописывает в файл строку JSON с формой ответа — метод и адрес без query (UUID и числа пути — `{id}`), статус, пути полей тела с видом значения (`uuid`, `name`, `number`…). Значений полей тела, заголовков, query и тел запросов в файле нет; ключи объектов не формы имени поля — `*`; тело не JSON — `"form":"not-json"`. Остаются хост и сегменты пути, кроме UUID и чисел: имя бакета и ключ объекта S3, имя DNS-зоны, имена ресурсов в пути — файл не публикуйте. Файл создаётся с правами 0600 и только дописывается; без переменной ничего не пишется. Ответ запись не меняет; первые 1 МБ тела читаются до того, как их получит команда. Из таких файлов собирается каталог живых ответов, по которому сверяются тестовые миры evo.
