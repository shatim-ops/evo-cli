### Безопасность

- **Отказы `evo mcp` и политики MCP по HTTP не повторяют введённое.** Было:
  - `evo mcp --auth <значение>` печатал значение («unknown --auth "…"»), в том числе с `--json --dry-run`; отказы
    `--auth none` не на loopback и короткого `MCP_BEARER_TOKEN` не на loopback печатали адрес `--http` целиком;
  - `evo mcp --toolsets <группа>` и `evo agent setup --toolsets` печатали неизвестную группу в нижнем регистре;
  - отказ `k8s_kubectl` по HTTP называл флаг, запрещённый по форме имени (`--…file`, `--…-dir`), введённым именем, а флаг перед
    командой — первым словом целиком, со значением («got "--token=…" first»).

  Стало:
  - «unknown --auth value» с допустимыми режимами; отказы `--auth none` и короткого токена — без адреса (токен не
    печатался и прежде);
  - «unknown toolset (item N of the list)» со списком групп;
  - флаг, запрещённый по форме, назван местом («flag in word N»), а имена из закрытого списка — как прежде; флаг перед
    командой — «word 1 is a flag».

  `reason` и коды выхода не меняются.
