### Безопасность

- **Отказы `evo mcp` и политики MCP по HTTP не повторяют введённое.** Было:
  - `evo mcp --auth <значение>` печатал значение («unknown --auth "…"»), в том числе с `--json --dry-run`;
  - `evo mcp --toolsets <группа>` и `evo agent setup --toolsets` печатали неизвестную группу в нижнем регистре;
  - отказ `k8s_kubectl` по HTTP называл флаг, запрещённый по форме имени (`--…file`, `--…-dir`), введённым именем.

  Стало:
  - «unknown --auth value» с допустимыми режимами;
  - «unknown toolset (item N of the list)» со списком групп;
  - флаг, запрещённый по форме, назван местом («flag in word N»), а имена из закрытого списка — как прежде.

  `reason` и коды выхода не меняются.
