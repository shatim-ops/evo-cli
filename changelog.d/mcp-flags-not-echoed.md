### Безопасность

- **Отказы `evo mcp --auth`, `evo mcp --toolsets` и политики kubectl по MCP
  HTTP не повторяют введённое.** Было: «unknown --auth "<значение>"»
  (в том числе с `--json --dry-run`); адрес `--http` в отказах `--auth none`
  и короткого `MCP_BEARER_TOKEN`; «unknown toolset "<группа>"» — в нижнем
  регистре, но целиком; имя флага kubectl, запрещённого по форме (`file` в
  имени, окончание `-dir`), — как его ввели. Стало: режим, адрес и группа
  не повторяются — отказ называет флаг, допустимые значения и место группы
  в списке («item 2 of the list»); флаг kubectl из закрытого списка назван
  по имени, запрещённый по форме — местом («the flag in argument 3»).
  `reason` и коды выхода не меняются.
