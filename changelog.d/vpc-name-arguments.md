### Добавлено

- В CLI и MCP VPC можно выбрать по имени в текущем проекте. Например, `evo vpc get private-net` открывает карточку сети. Если имя встречается несколько раз, evo показывает UUID совпадений до запроса согласия. В превью маршрута видны UUID и доступное имя VPC.

### Исправлено

- При фильтрации подсетей, балансировщиков и групп целей по имени VPC неполный каталог проекта теперь даёт `API_ERROR` (CLI — код 5). Раньше после совпадения на первой странице повреждённая следующая страница могла привести к выдаче результата с кодом 0.
