### Добавлено

- **Журнал сессии для догфуда: `evo diag on`, `evo diag off`, `evo diag
  status`, `evo diag export`** (DECISIONS D46). Локальный файл рядом с
  `config.yaml` с каждым вызовом инструмента через CLI и MCP: инструмент,
  имена аргументов без значений, код ошибки, согласие, длительность, размер
  ответа, версия evo и метка сессии. Выключен по умолчанию; включается в
  конфигурации, а не флагом запуска; один файл на весь период с лимитом 16
  МБ и явной записью о переполнении. Никуда не отправляется. Описание —
  `docs/journal.md`.

### Известные ограничения

- Отказ, который CLI даёт до вызова инструмента (неизвестный флаг, нет
  обязательного аргумента), в журнал сессии не попадает; тот же отказ по MCP
  записывается.
