### Изменено

- **`evo agent setup` по умолчанию даёт агенту и группу `auth`
  (`whoami`, `doctor`).** Описание `whoami` велит агенту вызвать его первым,
  когда вызовы падают на ключе или попадают в чужой проект, но без
  `--toolsets` агент получал только `deploy,vm,vpc,disk,image` и видел «Tool
  whoami not found». Теперь умолчание — `deploy,vm,vpc,disk,image,auth`: два
  инструмента, оба только читают. Запись клиента, которую поставил evo 1.7.2
  с прежним умолчанием, повторный `evo agent setup` без `--toolsets` заменяет
  как свою — после diff и согласия, без `--force`, с кодом 0. Запись, которую
  правил человек, без `--force` не меняется.
