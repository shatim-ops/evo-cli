### Известные ограничения

- Превью create внутри родителя, которого вызов называет по id (база и пользователь в кластере PostgreSQL, группа узлов Kubernetes, запись DNS, маршрут VPC), называет проект вызова. С ключом организации без `--allow-project` и родителем в другом проекте это проект профиля, а не проект родителя, куда ресурс будет записан. С `--allow-project` такой родитель — `NOT_FOUND` до вопроса. Подробнее — `docs/mcp.md`, «Подтверждения».
