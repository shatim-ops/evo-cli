### Изменено

- Отказы, которые видны без записи в облако, приходят одним ответом, а не
  по одному на запуск: `evo vm create` и MCP `provision` без образа и без
  зоны называют оба; образ, которого нет в каталоге, и зона без подсети
  проекта — тоже оба. Первый по порядку проверки остаётся ошибкой ответа:
  `reason`, код выхода и подсказка — его, как раньше. Все — в поле
  `refusals` (в `--json` CLI — `details.refusals`); `missing` называет
  каждый недостающий аргумент. CLI пишет каждый отказ строкой и подсказку
  своими флагами для каждого.
