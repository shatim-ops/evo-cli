### Изменено

- **`vm_resize` (`evo vm resize`) с id flavor, который уже стоит на ВМ,
  отвечает по одной карточке ВМ.** Было: повтор читал ВМ и весь каталог
  flavor проекта, прежде чем ответить `already_resized`. Стало: устоявшаяся
  ВМ, у которой в карточке тот же id flavor, отвечает `already_resized` без
  чтения каталога — одно обращение к облаку вместо двух, без вопроса и без
  записи; недоступный каталог такому повтору не мешает. По имени flavor
  каталог читается, как раньше. Статус, поля ответа и коды выхода не
  меняются.
