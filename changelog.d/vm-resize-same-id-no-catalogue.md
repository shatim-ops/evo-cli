### Изменено

- **`vm_resize` (`evo vm resize`) с id flavor, который уже стоит на ВМ,
  отвечает по одной карточке ВМ.** Было: повтор читал ВМ и весь каталог
  flavor проекта, прежде чем ответить `already_resized`. Стало: устоявшаяся
  ВМ, у которой в карточке тот же id flavor (с именем), отвечает
  `already_resized` без чтения каталога — одно обращение к облаку вместо
  двух, без вопроса и без записи. Два случая меняют исход повтора по id с
  отказа на успех: каталог flavor не читается (была ошибка
  чтения каталога с её кодом выхода) и flavor ВМ нет в каталоге проекта
  (был отказ «flavor не найден», код выхода использования) — теперь в обоих
  `already_resized`, код выхода 0: ВМ уже на этом flavor. По имени flavor,
  у ВМ в переходном состоянии и при карточке без имени flavor каталог
  читается, как раньше.
