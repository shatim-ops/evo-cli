### Изменено

- **`evo completion zsh` включает выбор подсказки стрелками для evo, `evo doctor` называет второй evo в `PATH`** (план 1.7, Tab, #718; догфуд на macOS).
  Было: в zsh без своей настройки меню Tab по командам evo только печатал список кандидатов, стрелками выбрать было нельзя; если в `PATH` два evo (старый в `/usr/local/bin`, новый в `~/.local/bin`), оболочка запускала и дополняла первый, и это ничем не обнаруживалось.
  Стало: скрипт `evo completion zsh` задаёт `zstyle ':completion:*:*:evo:*' menu yes select` — только для evo и только если у вас нет своего стиля для evo (`zstyle -L`); свой стиль, заданный в `~/.zshrc`, остаётся в силе. `evo doctor` показывает предупреждение «other evo» для каждого другого evo в `PATH` (в Windows — с расширениями `PATHEXT`) с путём и версией; для версии он запускает тот файл с `version --json` (до 3 с). Коды выхода и остальные проверки не изменились.
