### Миграция

- При обрыве создания DNS-записи, статического маршрута или платного шлюза SNAT прежний повтор мог отправить второй запрос. С 1.10, пока исход неизвестен, CLI возвращает код 3, MCP — `confirmation_required` с `interrupted`. Новый ответ человека, `--yes`, `confirmed=true` и смена сессии сохраняют удержание. Проверьте цель через `dns_records`, `vpc_routes` или `snat_list` в том же проекте. Если цель видна, повтор сообщает её ID. Пустой список не доказывает отказ. Для дальнейшей сверки используйте HTTP-сессию с выданным при `initialize` заголовком `Mcp-Session-Id`, stdio или интерактивный терминал с общим каталогом состояния. Для действительно необходимого нового создания после доказанного отказа или неотправки получите новое согласие. Решение D119 расширяет D107.
