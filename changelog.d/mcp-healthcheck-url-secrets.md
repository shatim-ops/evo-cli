### Безопасность

- **`evo mcp healthcheck` не повторяет пароль и query адреса.** Было:
  при успехе поле `url` ответа `--json`, а при отказе текст ошибки
  повторяли адрес из `--url` или `MCP_HEALTHCHECK_URL` целиком — с паролем
  (`user:пароль@`) и query (`?token=…`). Стало: команда называет адрес
  без userinfo, query и fragment — схема, хост и путь; адрес, который не
  разбирается или не является URL http или https с хостом, получает отказ
  до запроса и не повторяется. Коды выхода прежние.
