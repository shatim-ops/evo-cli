### Добавлено

- `evo doctor` проверяет запись evo в настройках Claude Desktop (macOS, Windows), если она есть: evo по записанному полному пути на месте и это тот же evo, а профиль из `--profile` есть в каталоге настроек по умолчанию (приложение не получает `CLOUDRU_CONFIG_DIR`). Иначе — предупреждение с командой `evo agent setup --client claude-desktop`, которая запишет запись заново: после переноса или замены evo приложение молча перестаёт его запускать, и раньше evo этого не говорил. Код выхода `doctor` от этой проверки не меняется.
