### Безопасность

- **Запись намерения из каталога проекта больше не удаляет чужие файлы.**
  `evo doctor` и каждая команда читают записи `.evo/intents/`, а этот
  каталог может прийти вместе с репозиторием. Раньше путь удаления
  закрытой записи строился из поля `id` её содержимого, и подложенная
  запись заставляла `evo doctor` удалить файл вне каталога намерений,
  например `.evo/state.json`. Теперь `id` записи — только имя её файла в
  форме, которую пишет evo. Запись другой формы, с другим `id` внутри или
  ссылкой не читается и ничего не удаляет.
- **Текст записи намерения больше не звучит как слова evo.** Поля записи
  (заметка, инструмент, имя, проект, зона) входят в `pending_operations`, в
  `evo doctor` и в предупреждение каждой команды одной строкой в кавычках,
  как имена ресурсов из облака. Первый ответ MCP с `pending_operations`
  называет это поле в `_untrusted`.
