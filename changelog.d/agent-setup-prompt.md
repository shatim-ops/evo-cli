### Добавлено

- **Подключение агента одной вставкой: [docs/agent-setup.md](docs/agent-setup.md).** Человек говорит своему агенту «Настрой evo по <ссылке>», агент проверяет evo, запускает `evo login --for agent` и `evo agent setup --client <свой> --profile agent`. Доступ выдаёт только человек кнопкой «Выдать доступ» на странице Evolution CMCP: промпт запрещает агенту открывать эту страницу и адреса `127.0.0.1`, просить секрет и читать файлы ключей. По SSH и в контейнере — путь через ключ из личного кабинета и `evo configure`.
