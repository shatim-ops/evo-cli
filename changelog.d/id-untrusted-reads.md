### Безопасность

- **id из облака в чтениях и повторах помечен `_untrusted`.** Было: `id` у
  `vm_get`, `backup_get` и `k8s_nodepool_get` и `repeat_of` у повтора
  создания приходили без метки, хотя их значение даёт облако, а
  форма id на пути не проверяется; в `message` повтора id прошлого вызова
  стоял без кавычек. Стало: эти поля помечены, `repeat_of` — в
  центральном списке полей метки; id в `message` — в кавычках, на одной
  строке.
