### Безопасность

- **Повтор создания не исполняет сохранённый шаг-запись без согласия.**
  Было: повтор создания, чей ресурс платформа приняла, но список ещё не
  показывает, исполнял сохранённый шаг из файла состояния (`made/`) с его
  `confirmed: true` — до вопроса о согласии и без записи о вызове. Повтор
  `disk_create` с `attach_to` без `confirmed` подключал диск к ВМ; файл с
  пустым ключом, принесённый с каталогом состояния, исполнялся как свой.
  Стало: шаг исполняется, только если это чтение; шаг, который меняет
  ресурс, назван в `next_tool` без согласия и не выполнен; файл не хранит
  согласие вызова; файл без ключа, который его записал, не читается.
