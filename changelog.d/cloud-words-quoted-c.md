### Безопасность

- **Ошибки и отказы печатают статус, состояние и id из облака в кавычках.** Было: в 22 местах текста evo —
  ошибках и отказах удаления, создания, `deploy`, `provision`, дисков, правил групп безопасности, floating IP,
  стеков — значение из облака стояло без кавычек; перевод строки в нём читался бы как слова evo для человека и
  модели. Стало: значение — в кавычках с экранированием (`id "…"`, `status "…"`). Так же — состояние ВМ в поле `note` ответа `deploy_apply`. Команда списка с id созданного ресурса (`list_subnets ids=[…]`) в подсказке `subnet_create` и `snat_create` — только для id формы UUID, как прежде без кавычек; id другой формы назван в тексте в кавычках, без команды. `reason` и коды не меняются.
