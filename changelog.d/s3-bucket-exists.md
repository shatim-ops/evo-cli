### Миграция

- **`evo s3 bucket-create` / `s3_bucket_create` на свой существующий бакет отвечает `already_exists`, код 0, без вопроса** (DECISIONS D101). Было: вопрос о согласии (код 3), а с `--yes` или `confirmed=true` — `status: created` о бакете, который этот вызов не создавал; сценарий «удали созданное мной» мог удалить прежний бакет. Стало: evo читает бакеты профиля до вопроса; бакет с этим именем есть — `status: already_exists`, код 0, без вопроса и без записи. Что поменять: скрипт, который на повторе ждал код 3 или `created`, получает код 0 и `already_exists`; бакет из такого ответа не считайте созданным этим вызовом. Превью и `--dry-run` нового бакета теперь делают один запрос к Object Storage (список бакетов): без сети — отказ `API_UNREACHABLE` до вопроса, а не превью.
