### Добавлено

- **Журнал изменений `.evo/history/`** (D43, минимум 1.9). Каждый вызов, который меняет облако и прошёл согласие, оставляет строку в файле дня `.evo/history/ГГГГ-ММ-ДД.jsonl` рядом с `.evo/intents/`: время, инструмент, поверхность, проект, зона, имя ресурса, id ресурса и операции из ответа, итог (`created`, `deleted`, `already_deleted`, `changed`, `error`, `unknown`, `found`), код ошибки и id записи намерения. Прерванный вызов — строка `unknown`; вызов, который позже прочитал, чем тот закончился, дописывает строку `found` с тем же id. `evo login` пишет строку в каталог конфигурации. Значений аргументов и секретов в строке нет; файл `0600`, только дозапись, выключателя нет. Строку не удалось записать — ответ вызова прежний, в stderr одна строка предупреждения. Чтение — `evo history`; уборка по журналу — следующим PR.
