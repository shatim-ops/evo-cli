### Миграция

- Списки ресурсов и каталогов Compute, VPC, DNS, NLB, PostgreSQL, DBaaS, Kubernetes, Container Apps, Artifact Registry, секретов и сертификатов, а также списки прав, проектов, событий аудита и строк расходов отклоняют HTTP 200 с телом `null` вместо страницы или с элементом `null` вместо объекта. Раньше повреждённая выдача могла дать код 0 и выглядеть пустой или полной, хотя содержала только ранние страницы. Теперь затронутая операция CLI возвращает код 5 (`API_ERROR`), MCP — `result.isError: true`. Корректные пустые массивы принимаются. Для необязательного поля отсутствие допустимо; в ответах, где поле обязательно, требуется массив. Прежнее правило для поля `clusters` списка кластеров Redis/Kafka сохраняется.
  При переходе проверяйте ошибку до расчёта стоимости, вывода об отсутствии объекта или подготовки записи. При отказе повторите чтение после восстановления сервиса. Если исход предыдущей записи неизвестен, сначала установите его отдельно. (D122)
