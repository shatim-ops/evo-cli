### Миграция

- Списки ресурсов и каталогов Compute, VPC, DNS, NLB, PostgreSQL, DBaaS, Kubernetes, Container Apps, Artifact Registry, секретов и сертификатов, а также списки прав, проектов, событий аудита и строк расходов отклоняют HTTP 200 с телом `null` вместо страницы или с элементом `null` вместо объекта. Раньше повреждённая выдача могла дать код 0 и выглядеть пустой или полной, хотя содержала только ранние страницы. Теперь затронутая операция CLI возвращает код 5 (`API_ERROR`), MCP — `result.isError: true`. Корректные пустые массивы принимаются. Для необязательного поля отсутствие допустимо; в ответах, где поле обязательно, требуется массив. Если повреждён каталог проектов, `evo project use` по имени или UUID и автоматический выбор проекта в `evo configure` завершаются до сохранения профиля. При штатном отказе сервиса перечислить проекты явно переданный UUID по-прежнему можно сохранить с предупреждением. Прежнее правило для поля `clusters` списка кластеров Redis/Kafka сохраняется.
  При переходе проверяйте ошибку до расчёта стоимости, вывода об отсутствии объекта или подготовки записи. При отказе повторите чтение после восстановления сервиса. Если исход предыдущей записи неизвестен, сначала установите его отдельно. (D122)
