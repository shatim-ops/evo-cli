### Добавлено

- **Карточки групп читаются и по MCP: инструмент `agent_skill`.** Клиент без
  терминала получает карточку группы — её инструменты, откуда берутся id, чем
  удаляется созданное, чем ждать, заметки группы — вызовом `agent_skill` с
  аргументом `group`; без аргумента — перечень групп. Инструмент только читает
  реестр evo, к облаку не обращается, виден при любом `--toolsets` и с
  `--read-only`. Карточка по MCP — без колонки команд CLI; инструмент, которого
  сервер не отдаёт, помечен «not on this server». `evo agent skill --group`
  печатает прежнюю карточку; его `--json` теперь несёт и поле `group`.
