Решения по выпуску приведены в [передаче 1.10](../handoff/1.10.md). Предыдущая смена описана в [передаче 1.9](../handoff/1.9-relay.md).

## Очередь

1. Исправить замечания Грока, сопоставить каждое с исходной и повторной проверкой.
2. Получить заключения Процесса и Риска на одной совмещённой ревизии.
3. Передать проверенный diff Гроку для дополнения к аудиту. Передать релизную ветку Fable.

## Ждёт решения

Для GitHub CI, живого cloud-e2e, публикации и тега нужны отдельные разрешения владельца.

## Постоянные разрешения

Владелец разрешил местные правки по аудиту в ветках astra и синтетические проверки в Codex Cloud. Исключение для классификатора ограничено локальным выбором opsevo при изменении tools_backup.go и тестом этого правила.

## Стопы и лимит

Слияние в main, автослияние и очередь слияния запрещены. Согласованные сроки тестовой описи сохраняются.

## Известное красное

Процесс ведёт учёт тестового долга. Полный повтор на совмещённой ревизии и независимый аудит релизной ветки остаются открытыми.
