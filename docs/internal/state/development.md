## Постоянные разрешения

- Находки «критично» и «высокая» от «релиза» — без отдельного «да»; ломающее или размер L — сначала «релизу» и владельцу.
- Вливать `main` в свои PR merge-коммитом; ветку чужого PR не трогаю.
- Тема единственного коммита PR — как заголовок PR.
- Перед push — `go test ./...` поверх свежего `main` по коду выхода, не по выводу через `grep` (урок ночи 29.10: красный #565 ушёл в push).
