5. B: версия Kubernetes; PostgreSQL, Kafka, Redis — после двух прогонов проб.

7. C: «одной вставкой», IAM на чтение, `doctor`; шов транспорта, шлюз модулей.

## Стопы и лимит

- Операция В1 не начинается до слияния Н1–Н3 и блока 0в.

- Строка о цене — только после пробы цены; иначе «цена неизвестна, ресурс платный».
- Общие файлы реестра — только свои строки; генерируемое не сливать руками.
- Объём владельца сам не откладываю — только вопросом.
- Живое облако — нет; платформа — только в `evo-internal`.
- Тексты для модели и согласие — «Риск» до слияния.
