# Этап 0 — Лицензия Apache-2.0

Решение D1. Маленький этап, делается первым или вместе с этапом 1.

## Задачи

1. Заменить `LICENSE` на полный текст Apache License 2.0 (с appendix «How to
   apply»). Правообладатель и год — как в текущем файле: `Copyright 2026 shatim-ops`
   (владелец подтверждает юрлицо до мержа PR).
2. Добавить `NOTICE`: имя проекта, copyright, строка «This product includes
   software developed by third parties; see go.mod» — без перечисления.
3. README: убрать абзац про «внутренний код», добавить строку «Лицензия: Apache-2.0».
4. Проверить лицензии зависимостей из `go.mod` (`go-licenses report ./...` или
   вручную): все должны быть совместимы с Apache-2.0 (MIT/BSD/Apache). Результат
   — таблица в описании PR, не в репозитории.

## Не делать

- Не менять путь модуля и имя (этап 10).
- Не добавлять заголовки лицензии в каждый `.go`-файл (не требуется Apache-2.0; шум в diff).

## Критерии приёмки

- `head -3 LICENSE` — «Apache License / Version 2.0, January 2004».
- В описании PR — таблица зависимостей с лицензиями, ни одной GPL/AGPL/SSPL.
