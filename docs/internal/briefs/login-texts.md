# Тексты входа: `evo login` и `evo logout`

Русские тексты входа: страница согласия, «Готово», «Отменено», ошибка, терминал, ошибки для терминала и JSON, `evo logout`, справка. Бриф — источник текстов для макета окон входа (решение релиза 10.11), поэтому он совпадает с кодом. Источник истины — `internal/login/texts.go`. Правка текста в коде правит и этот бриф в том же PR. Тексты окна в личном кабинете Cloud.ru (цель, не 1.8) живут в прототипе дизайна и в `texts.go` не входят.

Редакция — сессия «Тексты входа — редактура», 05.11.2026, по редполитике Cloud.ru для текстов интерфейса и с решениями владельца (B-3, #1000). Перенос в код — #1013. Текст согласия проверил «Риск»: заключение 26 (#1014), условия к D34 — заключение 27 (#1017). Позже тексты менялись по заключениям 57, 58, 59, 63 и 67. Сверено с кодом 10.11 («1.8 — разработка B», от `main` e4262b13): все ключи брифа — имена функций в коде.

## Как читать

- Ключ — имя функции в `texts.go` (страницы — ещё и `pages.go`).
- `%s` и `%d` — подстановки.
- **[Р]** — текст согласия, его смысл сверяет «Риск». Без заключения «Риска» не менять.
- Где страница и терминал говорят об одном разными словами, у них **разные ключи**.

## Сквозные правила

| Правило | Как |
|---|---|
| Буква «ё» | Не используется (решение владельца 05.11): «удален», «истечет», «еще», «все» |
| Имя продукта | **Evolution CMCP** — только на страницах входа (D34, вариант А, #1015; `product.PageName`). В терминале, MCP и README — «evo CMCP»; в строках терминала продукт обычно не называется. `evo` — имя команды и аккаунтов `evo`, `evo-agent` |
| Место в облаке | «личный кабинет Cloud.ru», не «консоль». «Cloud.ru» не повторяется в одной фразе |
| Действие над ключом | «удалить», «удален». Так работает код (`DeleteAccessKey`) |
| Место ключа | «на этом компьютере», не «на этой машине» |
| Страница и терминал | Страница называет действия на ней («Выдать доступ», «выйдите из Evolution CMCP») и путь назад — «вернитесь в терминал и запустите evo login снова». Пока вход ждет, страница не советует новый вход без «отмените текущий»: второй `evo login` не начнется (`STATE_LOCKED`; заключение 58). В терминале и JSON — команды (`evo login`, `evo logout`) |
| Имя профиля и проекта во фразе | В «ёлочках»: профиль «agent», проект «radar-prod» |
| Точки | `message` — со строчной, без точки. `hint` — с прописной, с точкой. На странице: одно предложение — без точки; в нескольких — без точки в последнем |
| Повтор | Если повтор не поможет, так и пишем: «Повтор не поможет» |

## 8. Справка `evo login`

| Ключ | Текст |
|---|---|
| TLoginShort | Войти в Cloud.ru через браузер и записать ключ доступа в профиль |
| TLoginLong | Войти в Cloud.ru через браузер и выдать доступ на странице Evolution CMCP, которую evo открывает на этом компьютере: проект, для кого ключ (вам — аккаунт evo, текущий профиль; агенту — аккаунт evo-agent, профиль «agent») и срок (7, 30 или 90 дней); по умолчанию — вам и 30 дней. В терминале evo ничего не спрашивает: выбор делается на странице. Доступ выдается только кнопкой «Выдать доступ» на странице, флага --yes нет. С вашими правами evo создает сервисный аккаунт или использует уже созданный, выдает ему роль «Администратор проекта» до конца срока ключа (если у аккаунта роль уже на дольше или бессрочно, она остается такой, срок называет итог), создает ключ и записывает его в профиль. Роль дает право удалять любые ресурсы проекта и управлять сервисными аккаунтами и ключами. Прежний ключ evo login для этого профиля удаляется. Ваши токены хранятся только в памяти, секрет ключа нигде не показывается. Отказ называет шаг и HTTP-статус. По SSH и в контейнере вход не пройдет. Отменить — evo logout. |
| TFlagNoBrowser | Не открывать браузер, только показать ссылку. Открыть ее нужно на этом же компьютере |
| TFlagProject | ID или имя проекта: на странице будет только он, отмеченный; проект проверяется после входа в браузере |
| TFlagFor | Для кого ключ: me (аккаунт evo, текущий профиль) или agent (аккаунт evo-agent, профиль «agent») |
| TFlagTTL | Срок ключа: 7d, 30d или 90d (по умолчанию 30d) |
