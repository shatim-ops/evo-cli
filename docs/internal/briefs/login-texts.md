# Тексты входа: `evo login` и `evo logout`

Итоговый набор русских текстов входа: страница согласия, «Готово», «Отменено», ошибка, терминал, ошибки для терминала и JSON, `evo logout`, справка. Разработка переносит их в `internal/login/texts.go` (#1013). Английские тексты — следующим шагом. Тексты окна в личном кабинете Cloud.ru (цель, не 1.8) живут в прототипе дизайна и в `texts.go` не входят.

Редакция — сессия «Тексты входа — редактура», 05.11.2026, по редполитике Cloud.ru для текстов интерфейса и с решениями владельца. Текст согласия проверил «Риск»: заключение 26 (#1014), условия к D34 — заключение 27 (#1017). Строка плана — B-3, #1000.

## Как читать

- Ключ — имя функции в `texts.go`. **[нов]** — такой строки в коде еще нет. **[лог]** — нужна правка логики или аргументов, а не только слов.
- `%s` и `%d` — подстановки. Число и порядок аргументов не меняются, если в строке не сказано иное.
- **[Р]** — текст согласия, его смысл сверяет «Риск». Без заключения «Риска» не менять.
- Где страница и терминал говорят об одном разными словами, у них **разные ключи**: страница называет действия, терминал — команды.

## Сквозные правила

| Правило | Как |
|---|---|
| Буква «ё» | Не используется (решение владельца 05.11): «удален», «истечет», «еще», «все» |
| Имя продукта | **Evolution CMCP** — только на страницах входа (D34, вариант А, #1015). В терминале, MCP и README — «evo CMCP»; в строках терминала продукт обычно не называется. `evo` — имя команды и аккаунтов `evo`, `evo-agent` |
| Место в облаке | «личный кабинет Cloud.ru», не «консоль». «Cloud.ru» не повторяется в одной фразе |
| Действие над ключом | «удалить», «удален». Так работает код (`DeleteAccessKey`) |
| Место ключа | «на этом компьютере», не «на этой машине» |
| Страница и терминал | На странице — действия («выйдите из Evolution CMCP», «запустите вход еще раз»): человек может работать из приложения агента, а не из терминала. В терминале и JSON — команды (`evo login`, `evo logout`) |
| Имя профиля и проекта во фразе | В «ёлочках»: профиль «agent», проект «radar-prod». **[лог]** Везде, где сейчас `%q`, нужно `«%s»`: `%q` выводит прямые кавычки |
| Точки | `message` — со строчной, без точки. `hint` — с прописной, с точкой. На странице: одно предложение — без точки; в нескольких — без точки в последнем |
| Повтор | Если повтор не поможет, так и пишем: «Повтор не поможет» |
