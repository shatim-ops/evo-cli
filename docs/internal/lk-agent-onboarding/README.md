# Агенты в ЛК Cloud.ru — прототип

Кликабельный прототип: куда и как встроить в личный кабинет Cloud.ru
подключение своего AI-агента (evo CLI + MCP-сервер). Один файл,
`prototype.html`, открывается в браузере без сборки.

## Экраны

| # | Экран | Решение |
|---|---|---|
| 0 | Концепция | Тезис, принципы, джобы, карта точек встраивания, путь пользователя |
| 1 | Главная | Переключатель «В консоли / В моём агенте» в блоке Гига-помощника, кнопка в шапке |
| 2 | Главная, режим агента | Единый компонент подключения: агент → права → промпт → ожидание |
| 3 | Меню сервисов | Выдача по «mcp», пункт «evo CLI и MCP» в «Разработке» |
| 4 | ВМ: пустой проект | Три равных способа: консоль, агент, код |
| 5 | Создание ВМ | «Повторить без консоли»: промпт / evo / Terraform из полей формы |
| 6 | Карточка ВМ | «Разобрать с агентом» в алерте, промпты с ID ресурса, действия агентов |
| 7 | Подтверждение доступа | Сверка кода, проект, права, срок, отдельный сервисный аккаунт |
| 8 | IAM → Агенты | Реестр агентов, отзыв, журнал с «подтверждено человеком» |
| 9 | Маркетплейс | Категория «Для AI-агентов (MCP)», партнёрские MCP-серверы |

Панель сверху: выбор экрана (или ← →), «Агент: подключён / не подключён»
переключает весь ЛК между состояниями, «Аннотации» прячет номера и панель
«Почему так», «Тема» — светлая и тёмная.

Маршрут для показа: 0 → 1 → 2 → «Скопировать промпт» → «Демо: открыть
ссылку» → 7 → «Разрешить доступ» → 6 → 8 → 5 → 9.

## Допущения

- Главная и меню сервисов повторяют скриншоты ЛК; страницы ВМ, IAM и
  Маркетплейса реконструированы — сверить с реальными.
- Цвета, радиусы и тени — токены Snack UIKit (`@snack-uikit/figma-tokens`
  19.0.5, тема brand). Шрифт SB Sans Interface, если не установлен,
  заменяется на Inter.
- Имена, суммы, IP-адреса и партнёры вымышлены; логотипы агентов — монограммы.
- `evo login`, адрес `cloud.ru/agents`, вкладка «Агенты» в IAM и категория
  в Маркетплейсе — предложения, а не существующие функции. Техническая
  проработка (device flow, создание ключа в IAM) — отдельным этапом.
