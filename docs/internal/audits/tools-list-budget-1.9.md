## 1. Метод

Бинарь из `main`, `evo mcp` по stdio: `initialize` → `tools/list`, длина
строки ответа в байтах. Сверка — `TestToolsList_SizeBudget` (тело без
конверта JSON-RPC). Состав считается по компактному JSON ответа. Размеры в
`docs/mcp.md` держит `TestDocsExamples_Counts` (допуск 10 %).

## 4. Прогноз 1.9 (оценка)

Новых инструментов по плану версии — 28–39: +26…37 КБ; сквозные аргументы
(теги, списки фильтров) — ещё +3…6 КБ. Итого +29…43 КБ при свободных
~38 КБ: волны В1 и В2 проходят; в верхнем сценарии предел пробивается на
последних волнах.

## 5. Варианты сжатия (факт об экономии, оценка риска)

| № | Что | Экономия, байт | Риск |
|---|---|---|---|
| 1 | `$ref`/`$defs` для общих аргументов | 0 | не работает: `inputSchema` — схема каждого инструмента, общих определений между инструментами спецификация MCP не даёт (modelcontextprotocol.io/specification/2025-06-18/server/tools) |
| 2 | описание `confirmed` до ~32 байт | 3 602 | текст для модели; правило согласия остаётся в описании инструмента |
| 3 | правило согласия один раз в `instructions` сервера (вместо 2) | ~6 500 | клиент, не показывающий модели `instructions`, теряет правило — гипотеза |
| 4 | описания `wait`, `wait_seconds` до 60 байт | 1 881 | текст для модели; пределы остаются в схеме |
| 5 | аннотации без значений по умолчанию спецификации | 660 | низкий по спецификации |
| 6 | описания инструментов длиннее 400 байт (31) — до 400 | до 6 453 | высокий: содержательный текст для модели; у `deploy`, `provision`, `deploy_plan`, `list_flavors` запаса нет (#1398) |
| 7 | постраничная выдача | 0 для контекста | клиент дочитывает все страницы |

Без содержательной потери — 2, 4, 5: около 6 КБ (≈ 7 инструментов). С
вариантом 3 — около 9 КБ; с вариантом 6 — до 15 КБ.

## 6. Вывод

Сжатие отодвигает предел байт на 7–15 инструментов и вопрос не снимает. В
верхнем сценарии нужен один из двух шагов, оба — решения владельца:

| Шаг | За | Против |
|---|---|---|
| поднять `maxToolsListBytes` | дёшево, обратимо | комментарий к константе запрещает; предел 128 инструментов у VS Code не лечит |
| `--toolsets` по умолчанию или обязательным | лечит и байты, и число инструментов | ломающее для клиентов без флага |

Инвариант «описание общего аргумента — одно на реестр» заводится вместе
со строкой плана о сжатии, не раньше: до неё закрывать его некому.
