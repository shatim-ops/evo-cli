# Независимый полный аудит выпуска 1.9, кандидат rc.1 (18.11.2026)

Полный аудит перед тегом minor по `CLAUDE.md` §5, отдельной сессией.
Поручение передано сообщением сессии «1.9 — релиз (4)» со ссылкой на «да»
владельца 18.11; строки плана или issue `решение` под него в `main` нет
(находка A19-34). Режим — только чтение: код, план, реестры и срезы ролей
не правились, в облако не ходил. Записи — этот отчёт и issue с находками.

Что сверено:
- **Предмет:** разница `v1.8.2..ab15af5` (стартовая голова `main`,
  `ab15af55ff1aca2a6e2930eaf716353b765ee632`): 1049 файлов, из них 163 файла
  продуктового Go, +19 101 / −3 066 строк. Реестр: 157 → 175 инструментов.
- **Досмотр:** `ab15af5..79ffd19` — отдельным разделом в конце.
- **Документы:** раздел 1.9 `release-plan.md` и строка «Граница rc.1 по
  находкам», `DECISIONS.md`, `docs/RELEASING.md`, журнал `risk/1.9.md` с
  черновиком сводки остаточных рисков, `delta-1.9-interim.md` (серия FB19I).

Метод: семь параллельных проходов по пунктам чек-листа §5, каждый — чтение
кода и пробы. Пробы — временные тесты в мирах пакетов `internal/tools` и
`internal/cli` и собранный `evo` без сети; временные файлы удалены. Шесть
находок, названных ниже высокими, перепроверены по коду вторым чтением.
«Факт» — воспроизведено пробой или однозначно читается по названным
строкам; «по чтению» — тестом не воспроизведено; «гипотеза» — не доказано.
Сведения о платформе здесь не приводятся: всё ниже — о коде evo; ответы
сервиса в пробах — синтетика. Серия находок — A19.

## Итог

**К rc.1 выпуск не готов.** Причины, по убыванию веса:

1. **Гейт согласия обходится сохранённым шагом (A19-1, #2418).** Вызов без
   согласия исполняет шаг из файла `made/` — любой инструмент реестра с
   `confirmed: true`. Путь без постороннего: повтор `disk_create` с
   `attach_to` сам отправляет привязку диска. «Релиз» принял как условие
   rc.1.
2. **Секреты в выводе — два новых пути класса условия rc.1 (A19-2, #2419;
   A19-3, #2420).** Ошибка облака с эхом тела раскрывает `env` у `ca_deploy`
   и `image_metadata` у `provision`; опечатка разделителя в `--meta` и
   `--env` печатает пару целиком, в том числе с `--dry-run`. «Релиз» принял
   как условия rc.1.
3. **Условие «метка `_untrusted`» не выполнено (A19-4…A19-6, #2425–#2427).**
   Имя ресурса из облака уходит вне метки у 12 из 88 инструментов, до
   которых дошла проба; причина — инварианты метки не доходят до облака у
   37 из 175 инструментов (A19-14, #2434).
4. **Условия rc.1, названные в поручении, слиты не все.** На `79ffd19`
   слиты #2403 и #2407; открыты #2396, #2406, #2412; под issue #2384 и #2386
   открытых PR нет.
5. **Строка плана со сроком «до rc.1» не исполнена (A19-7).** Расширение
   D100 на аргументы места внутри проекта: пустая строка проходит проверку
   у 218 пар «изменяющий инструмент — строковый аргумент».
6. **Гейты тега не пройдены (A19-18).** Фрагменты `changelog.d/` не
   свёрнуты; в таблице ломающих `RELEASING.md` нет ни одной строки 1.9;
   три резерва D версии 1.9 не заменены; сроки двух убывающих списков
   стоят «до rc.1» (перенос решён, #2181 не слит).

Что в порядке:
- **Паритет CLI–MCP:** блокеров нет; тесты `TestParity_*`, `TestContract_*`,
  `TestReadOnly_*` зелёные; у всех 18 новых инструментов есть команда.
- **«Миграция»:** ломающего, целиком не названного, не найдено. Схемы 157
  выпущенных инструментов: удалённых инструментов и аргументов — 0, новых
  обязательных — 0; 471 проба «код выхода и `reason`» двумя бинарями
  совпала. Одно неверное утверждение — A19-16.
- **Идемпотентность:** транспорт запись после обрыва не повторяет; D26 —
  одна точка. Обе high-находки промежуточного аудита (FB19I-30, FB19I-31)
  закрыты.
- **Секреты вне двух путей выше:** отказы разбора флагов и позиционных,
  типы аргументов, секретные записи, журналы и state, MCP HTTP, консоль ВМ
  — чисто.

Счёт находок: высоких — 7 (шесть с issue, седьмая — строка плана 94),
средних — 12, низких — 14 (одним issue #2435) и 5 замечаний к учёту.
Блокером по оценке аудита названа одна — A19-1; объём rc.1 решает владелец
по строке «Граница rc.1».
