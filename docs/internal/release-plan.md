## Вопросы к платформе

- **IAM:** можно ли выдать сервисному аккаунту роль на один сервис (Compute, DBaaS), а не на весь проект? Сейчас опубликованы роли уровня проекта и роли Kubernetes и Object Storage (`docs/auth.md`, «Роли»). Пункты 1.2.1 и 1.3 от ответа не зависят: доступ определяется по факту (403 на дешёвое чтение в `doctor`); от ответа зависит, насколько тонко можно выдавать права.
- **DevTools (для 1.4):** принимает ли API Repo и Workflow Studio `Authorization: Bearer <IAM-токен>` сервисного аккаунта; какой базовый URL канонический; актуальная публичная спецификация и поле `port`; кто сообщает о ломающих изменениях API. До ответа — живая проба Bearer (только чтение).
- **Evolution Protection Platform:** API для интеграции проверок безопасности.
