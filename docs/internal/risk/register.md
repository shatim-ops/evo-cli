# Реестр рисков evo

Хозяин — «Риск · N» (`CLAUDE.md` §0, правило 7; проект роли —
`docs/internal/briefs/risk-role.md`). Сверяет и ставит хвост «риск: R-N» в
строках D и плана — «N — релиз».

Правила записи:
- одна строка — один риск; повтор в новой версии — новая дата в «Статусе», не дубль;
- В/Л — вероятность/влияние, 1–3 (бриф роли, §3); «?» — нет данных, оценка после факта;
- статусы: **открыт** → **принят** (владелец, ссылка на «да») / **снижен** (PR, тест или строка D) / **закрыт** (решение снято) / **вопрос владельцу** (issue `решение`);
- платформа Cloud.ru, атаки и обходы с конкретикой — только `shatim-ops/evo-internal`, `risk/`; здесь — «подробности в evo-internal»;
- никаких реальных ID, IP и ключей: репозиторий публичный.

Заключения, на которых стоят строки, — `risk/<версия>.md`. Номера находок
(№N) — `evo-internal` `runs/claude-agent-1.7.0-cloud/findings.md`.
