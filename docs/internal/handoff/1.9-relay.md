## 3. Сверка при старте (до любого действия)

```bash
# 1. Теги и релизы: есть ли rc.2
gh api repos/shatim-ops/evo-cli/git/matching-refs/tags/v1.9.0 --jq '.[].ref'
gh api repos/shatim-ops/evo-cli/releases --jq '.[0:3][]|.tag_name+" "+(.prerelease|tostring)'
# 2. Голова main и её CI
gh api repos/shatim-ops/evo-cli/commits/main --jq '.sha+" "+(.commit.message|split("\n")[0])'
gh api "repos/shatim-ops/evo-cli/actions/runs?branch=main&event=push&per_page=6" \
  --jq '.workflow_runs[]|select(.name=="ci")|.head_sha[0:8]+" "+.status+" "+(.conclusion//"")'
# 3. Открытые PR
gh api "repos/shatim-ops/evo-cli/pulls?state=open&per_page=60" \
  --jq '.[]|"\(.number) \(.head.sha[0:8]) auto=\(.auto_merge!=null) \(.title[0:70])"'
# 4. Свёрнут ли CHANGELOG (в changelog.d только README.md)
gh api repos/shatim-ops/evo-cli/contents/changelog.d --jq '.[].name'
# 5. Задания и находки внешней проверки (метки по-русски — через -f)
gh api -X GET repos/shatim-ops/evo-cli/issues -f labels="астра-задание" -f state=all \
  -f since=2026-11-18T19:00:00Z --jq '.[]|"\(.number) \(.state) \(.title[0:70])"'
gh api -X GET repos/shatim-ops/evo-cli/issues -f labels="внешняя-проверка" -f state=open \
  -f since=2026-11-18T19:00:00Z --jq '.[]|"\(.number) \(.title[0:80])"'
```

Затем прочитать раздел 9 этого файла (журнал ночи), срез
`state/release.md` и последние записи `risk/1.9.md`.
