# Передача дел между сессиями

Один файл на выпущенную версию: `<версия>.md` (`1.2.1.md`). Пишет релизная
сессия перед закрытием, после тега; новая сессия читает последний
(`CLAUDE.md`, «Старт сессии»). Одна страница, без внутренних сведений
Cloud.ru — репозиторий публичный; внутреннее — в приватных заметках
владельца.

Шаблон:

```markdown
# Передача: <версия> (<дата тега>)

## Выпущено
- тег, коммит, PR версии (ссылки); cloud-e2e — номер прогона.

## Метрики версии
- время PR от открытия до слияния: медиана и самые долгие с причиной;
- красные прогоны `ci` на `main` и в PR — с причиной;
- patch из-за дефекта в 48 ч после выпуска предыдущей версии;
- живые прогоны cloud-e2e за версию и их исход;
- открытые issue с меткой `деньги`.

## Открыто
- решения, которых ждёт владелец (вопрос — варианты — рекомендация);
- живые ветки и PR, кто их ведёт;
- известные риски и что их проверит.

## Следующая версия
- раздел `release-plan.md`, с чего начать и почему.

## Сессии
- какие сессии работают над продуктом и их роли.
```
