# Анонсы выпусков

Файл `<тег>.md` этого каталога — например, `v1.8.0.md` — goreleaser ставит
заголовком описания релиза на GitHub, над списком коммитов
(`.goreleaser.yaml`, `release.header`). Файла нет — у релиза только список
коммитов, как раньше.

Анонс пишет «релиз» в PR версии, до тега: что вошло, известные ограничения,
миграция (ссылкой на `CHANGELOG.md`). Текст публичный — без внутренних
сведений Cloud.ru (`CLAUDE.md`, §4).
